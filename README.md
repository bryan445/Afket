## 📌 About Afket

**Afket** is a Malawi-focused B2B marketplace and business connection platform designed to bridge the gap between suppliers, buyers, brokers, logistics providers, manufacturers and other businesses.

The platform aims to simplify business connections, improve market access and facilitate trade by creating a digital environment where businesses can discover opportunities, connect with potential partners and coordinate commercial activities.

Afket is being developed with the initial focus on Malawi, with a broader vision of facilitating regional and international trade.

### 🎯 The Problem

Many businesses, particularly smallholder farmers and agricultural suppliers, face challenges accessing reliable markets and connecting with large-scale buyers.

Similarly, hotels, manufacturers, retailers and other businesses often struggle to identify reliable suppliers and coordinate sourcing.

Afket aims to address these challenges through a unified digital platform.

---

## 🚀 Core Platform Capabilities

### 1. Digital Marketplace
A platform where businesses can discover products and potential trading partners.

### 2. Broker Management
Supporting brokers in connecting suppliers with buyers and coordinating agricultural trade.

### 3. Campaign Management
Enabling brokers and other authorised users to communicate specific supply and demand opportunities.

### 4. Business Connections
Bringing farmers, suppliers, buyers, manufacturers and logistics providers into one connected ecosystem.

### 5. Tender and Sourcing
Supporting business sourcing opportunities and tender-related workflows.

### 6. Logistics Connections
Connecting businesses with logistics providers to support the movement of goods.

## 💻 Local Development

To run the web application locally:

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/bryan445/Afket-Final.git
```

Navigate into the project:

```bash
cd Afket-Final
```

Install dependencies:

```bash
npm install
```

Configure the required Supabase environment variables using your local `.env` file.

Example:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Start the development server:

```bash
npm run dev
```

**Important:** Never commit private API keys, service-role keys, passwords or other sensitive credentials to GitHub.
